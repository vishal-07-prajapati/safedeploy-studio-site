How SQL Diff Studio Reduces Manual Workload

Built directly around real bottlenecks in multi-database SQL Server workflows.

1. Managing Multiple DB Migrations & SP Filters
Before: Scanning entire databases and manually running scripts across multiple target DBs.
→
With SQL Diff Studio: Pushes IN / LIKE filter to SQL Server, reducing manual workload across multiple DB migrations.
2. Deploying Without "Already Exists" Errors
Before: Manual CREATE scripts fail if SP exists, or forget pre-change backups.
→
With SQL Diff Studio: Saves rollback .sql first, runs standalone DROP, then CREATE.
3. CE21 Versioned SP Naming
Before: Manually stripping _13049627712_26_05 suffixes before deploying to target DBs.
→
With SQL Diff Studio: Auto-matches versioned SPs to base SPs only when entered, and renames on deploy.
4. Catching Slow Non-SARGable Queries
Before: YEAR(col), ISNULL(), and leading % wildcards slip into production unnoticed.
→
With SQL Diff Studio: Instant offline SARGability rules + optional AI rewrite suggestions.
Feature Spotlight 1 03 / 08

Targeted Comparison & Filters

Compare one or multiple database pairs in parallel with clean, noise-free results.

1

SQL-Level Pre-Filtering

Paste SP names in Only include (supports wildcards *, ?, or pasted DROP PROC lines). SQL Server returns only those matching objects.

2

Token-Normalized Diff

Ignores comments, casing, brackets, and whitespace so formatting differences never clutter real code changes.

3

Parallel Pairs & .scmp Import

Compare DEV → Local, CE21Root, and CE21Chat simultaneously or import Visual Studio .scmp files.

Feature Spotlight 2 04 / 08

Bulk Apply & Rollback Safety

Deploy single or multiple stored procedures safely across one or all tenant databases.

1

Multi-Select & "Apply ALL"

Select specific rows or click Apply ALL to review and deploy all modified procedures in one batch.

2

Pre-Change Rollback Snapshot

Before touching the target DB, the existing procedure definition is saved as a timestamped .sql rollback file.

3

Idempotent DROP + CREATE & Audit

Executes a standalone IF OBJECT_ID(...) DROP followed by CREATE with an embedded developer/ticket audit header.

Feature Spotlight 3 05 / 08

AI & SARGability Advisor

Optimize query performance before deploying—offline or with your own LLM key.

1

Offline Static SARGability Rules

Instantly flags YEAR(col), ISNULL(col, ...), leading % wildcards, SELECT *, and missing SET NOCOUNT ON.

2

AI Query Rewrite Suggestions

Connect Groq or OpenAI-compatible endpoints to get exact SARGable T-SQL rewrites and index recommendations.

3

Live Token Budget Meter

Displays remaining tokens, request quota, reset countdown, and per-call usage right inside the drawer.

Feature Spotlight 4 06 / 08

Enterprise Security & Auditability

Zero plaintext secrets on screen or disk, with shared team visibility.

1

Windows DPAPI Encryption

SQL Server passwords and AI API keys are encrypted per Windows account in %AppData%\SqlDiffStudio\settings.json.

2

Masked Keys & Connection Test

API keys stay masked by default with a Show/Hide toggle and a Test AI Connection button that reports live quota.

3

Shared Backup & History Log

Configure a shared team folder for rollback scripts and inspect deployment_history.log anytime.
