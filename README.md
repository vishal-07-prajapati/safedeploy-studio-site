# SQL Diff Studio — Product Showcase Website

This repository hosts the public product landing page and documentation showcase for **SQL Diff Studio**, deployed via **GitHub Pages**.

## Live Website
👉 [https://vishal-07-prajapati.github.io/safedeploy-studio-site](https://vishal-07-prajapati.github.io/safedeploy-studio-site)

## Features Included
- High-conversion SaaS landing page with dark/light themes.
- 6-step zero-risk deployment lifecycle visualizer.
- Feature highlights covering AST Guardrails, SARGability analyzer, and 1-click rollback.
- Architecture and technology overview.
- Download section for Windows .msi installer and portable zip packages.
- Direct links to the main source repository.

## Local Development
Open `index.html` in any modern web browser or run:
```bash
npx serve .
# or
python -m http.server 8080
```
