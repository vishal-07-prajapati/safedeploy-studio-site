Release Notes — v1.0.0 LTS

  • AST Guardrails Engine: Initial release of Abstract Syntax Tree validation powered by Microsoft.SqlServer.TransactSql.ScriptDom 180. Blocks physical table drops and alterations while permitting temporary staging tables (#temp).
  • Transactional Sandboxes: Implemented BEGIN TRAN ... ROLLBACK TRAN dry-run verification on target databases with clean rollback guarantee.
  • Backup Vault & 1-Click Rollback: Automated cryptographic pre-change snapshot synthesis with SHA-256 integrity validation.
  • SQL Diff Viewer: Whitespace-normalized line-by-line comparison powered by DiffPlex.
  • Deterministic SARGability Analyzer: Static query optimization warnings for date function traps, non-SARGable ISNULL predicates, and missing SET NOCOUNT ON.
  • Dual Interface: Full Blazor Server interactive workbench and native Windows WPF desktop shell with Microsoft WebView2 integration.
